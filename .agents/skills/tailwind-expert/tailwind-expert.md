# Tailwind Expert Skill

OBJETIVO:
Mejorar la calidad visual y arquitectura CSS utilizando TailwindCSS moderno.

IMPLEMENTAR:

DESIGN TOKENS:
- semantic colors
- CSS variables
- reusable utilities
- consistent spacing

DARK MODE:
- dark mode premium
- evitar negro absoluto
- utilizar slate/zinc/neutral
- contraste suave

LIGHT MODE:
- evitar blanco puro
- fondos suaves
- profundidad visual elegante

UTILIZAR:
- rounded-2xl
- soft shadows
- subtle borders
- backdrop blur sutil

TRANSITIONS:
- duration-200
- duration-300
- ease-in-out
- hover transitions suaves

HOVER:
- hover:bg
- hover:border
- hover:shadow
- hover:-translate-y

IMPORTANTE:
NO usar:
- colores hardcodeados
- sombras exageradas
- borders agresivos
- saturación excesiva

PRIORIDAD:
- consistencia
- mantenibilidad
- elegancia
