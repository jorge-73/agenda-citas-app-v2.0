# Design System Skill

OBJETIVO:
Crear consistencia visual total en toda la aplicación.

IMPLEMENTAR:

TOKENS:
- background
- foreground
- primary
- secondary
- muted
- accent
- border
- success
- warning
- destructive

TIPOGRAFÍA:
- heading hierarchy
- body hierarchy
- font weights
- line heights
- spacing

SPACING SYSTEM:
- consistent padding
- margins
- gaps
- section spacing

COMPONENTES:
Todos los componentes deben reutilizar:
- colores
- tamaños
- radios
- sombras
- spacing

BOTONES:
- variantes consistentes
- tamaños consistentes
- hover consistente

CARDS:
- mismo estilo visual
- misma profundidad
- mismos bordes
- misma jerarquía

IMPORTANTE:
NO crear componentes inconsistentes.

Toda la app debe sentirse:
- unificada
- coherente
- premium
